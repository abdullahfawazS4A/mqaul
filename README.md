# موقع محاسبة مقاولات — Frontend فقط

تطبيق React (Vite) + Tailwind CSS لمحاسبة أعمال المقاولات، بواجهة عربية RTL بالكامل.
**لا يوجد Backend ولا قاعدة بيانات** — كل البيانات في ذاكرة التطبيق، مع حفظ تلقائي في
`localStorage` لتبقى بعد إغلاق المتصفح، وإمكانية تصدير/استيراد نسخة احتياطية.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء للإنتاج
npm run preview  # معاينة البناء
```

## الأقسام

| المسار | الواجهة | الوصف |
| --- | --- | --- |
| `/` | لوحة المعلومات | ملخّص كل الأقسام + آخر حركات الصيرفة |
| `/treasury` | الصيرفة | إيداع/استلام، بحث وتصفية بالتاريخ والنوع، تعديل وحذف، تصدير CSV |
| `/debts` | الديون | رأس المال، الأشخاص، بحث وترتيب، إضافة دين وسند قبض |
| `/debts/:personId` | سجل الشخص | كل حركاته مع تعديل وحذف، كشف حساب للطباعة وتصدير CSV |
| `/lists` | القوائم | سجل القوائم (قيمة/ربح/حالة) + تبويب «ديون الأشخاص» الخاص بالقوائم |
| `/projects` | المشاريع | قائمة المشاريع مع بحث وملخص عام |
| `/projects/:id` | تفاصيل المشروع | إيداعات الشركاء، المصاريف، السلف + ملخص وطباعة وتصدير |
| `/settings` | النسخ الاحتياطي | تصدير/استيراد JSON، إعادة التعيين، مسح كل البيانات |

## نظاما الديون — معزولان تمامًا

المشترك بينهما هو **سجل الأشخاص فقط**؛ لا يتقاطعان في أي مبلغ:

| | دين الأشخاص (نقدي) | دين القوائم |
| --- | --- | --- |
| المكان | صفحة «الديون» | تبويب «ديون الأشخاص» داخل القوائم |
| المصدر | `debtEntries` + رأس المال | القوائم غير المقبوضة |
| المعنى | أعطينا مالًا ونستردّه | أرباح قوائم لم تُقبض بعد |
| الحساب | مجموع الديون − سندات القبض | مجموع أرباح القوائم `unpaid` |
| الأثر | يُنقص «الرصيد الكلي المتاح» | لا يمسّ رأس المال ولا الصيرفة |

## قواعد العمل المطبّقة

- **الصيرفة:** الرصيد = مجموع الإيداعات − مجموع الاستلامات، مرتّبة من الأحدث للأقدم.
- **الديون:** الرصيد الكلي المتاح = رأس المال − الديون القائمة.
  إضافة دين بمبلغ أكبر من الرصيد المتاح **مرفوضة** برسالة خطأ واضحة.
  **سند القبض بلا سقف** — يجوز استلام مبلغ أكبر من دين الشخص، فيصبح رصيده سالبًا أي «له» مبلغ لدينا.
- **القوائم:** اسم الشخص يُختار من الأشخاص المسجّلين في الديون فقط (لا أسماء حرة)،
  ولا يمكن حذف شخص مرتبط بقوائم. أرقام القوائم للعرض، ودين القائمة = ربحها غير المقبوض.
- **المشاريع:** لكل مشروع مجاميع الإيداعات والمصاريف والسلف، و«المتبقي تحت اليد» = (إيداعات + سلف) − مصاريف.
- **الحذف:** كل عملية حذف تمرّ بنافذة تأكيد، وحذف شخص/مشروع يتطلّب كتابة اسمه حرفيًا.

## ربط Backend لاحقًا

كل الوصول للبيانات يمر عبر `src/data/DataContext.jsx` — لا يستورد أي مكوّن واجهة بيانات مباشرة.

1. استبدل جسم الدوال داخل `DataContext.jsx` (مثل `addTreasuryEntry`, `addDebt`, `addProjectItem`)
   بنداءات `fetch`/`axios` مع الإبقاء على نفس التواقيع والقيم المُعادة.
2. استبدل `useState(initial(…))` بجلب البيانات، واحذف `mockData.js` و`storage.js`.
3. الدوال التي تُرجع `{ ok, error }` تُبقي نفس الشكل حتى تستمر رسائل الخطأ بالظهور داخل النماذج.

المكوّنات و`hooks` لن تحتاج أي تعديل.
